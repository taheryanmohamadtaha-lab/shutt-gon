# 🎮 عملیات سایه — Shadow Operation

بازی تیراندازی سه‌بعدی اول‌شخص (FPS) با منوی کاملاً فارسی، ساخته‌شده با **HTML5 + Three.js + Capacitor**. بازی روی گوشی و تبلت اندرویدی اجرا می‌شود و پس از نصب، کاملاً **آفلاین** کار می‌کند.

---

## ✨ امکانات بازی

- **۸ مرحله** با داستان زنجیره‌ای و محیط‌های متفاوت (کوهستان، شهر جنگ‌زده، بیابان، جنگل، بندر شبانه، پایگاه زیرزمینی، برفی)
- **۷ سلاح** اختصاصی: تفنگ تهاجمی، مسلسل سبک و سنگین، تک‌تیرانداز، شاتگان، کلت و سلاح ویژه انرژی
- **سیستم ارتقای سلاح** (قدرت، دقت، خشاب، سرعت شلیک) + فروشگاه داخل بازی
- **۶ نوع دشمن هوشمند**: سرباز، مهاجم سریع، تک‌تیرانداز، نیروی زرهی، سلاح سنگین و فرمانده (باس‌فایت)
- هوش مصنوعی دشمن: گشت‌زنی، پناه گرفتن، عقب‌نشینی، درخواست نیروی کمکی و حمله گروهی
- **کنترل لمسی حرفه‌ای**: جوی‌استیک، چرخش دوربین، شلیک، نشانه‌گیری، نارنجک، خم شدن و دویدن
- نجات گروگان، نابودی مخازن سوخت، مأموریت تک‌تیراندازی و نبرد نهایی با فرمانده
- سیستم درجه نظامی، امتیاز، پول بازی، مأموریت روزانه و دستاوردها
- ذخیره خودکار پیشرفت در گوشی (LocalStorage)
- صدا و موسیقی رویه‌ای با Web Audio API (بدون فایل خارجی)
- نقشه کوچک زنده، افکت انفجار، رد گلوله، لرزش دوربین و دید شبانه
- کیفیت گرافیک قابل تنظیم (پایین / متوسط / بالا) برای گوشی‌های میان‌رده

## ▶️ اجرای بازی در مرورگر (بدون نصب)

کافی است فایل `index.html` را در مرورگر باز کنید یا یک سرور محلی اجرا کنید:

```bash
npx serve .
# سپس در مرورگر: http://localhost:3000
```

> روی دسکتاپ با **WASD + ماوس** و روی موبایل با **کنترل لمسی** بازی کنید.

## 📱 ساخت فایل APK اندروید با GitHub Actions (خودکار)

### مرحله ۱: ساخت مخزن در GitHub
1. وارد [github.com](https://github.com) شوید و یک مخزن جدید بسازید (مثلاً با نام `shadow-operation`).
2. همه فایل‌های این پروژه را در مخزن آپلود کنید (دکمه **Add file → Upload files**).

### مرحله ۲: ساخت خودکار APK
- فایل `.github/workflows/build-apk.yml` از قبل در پروژه قرار دارد.
- به محض آپلود کد در شاخه `main`، گیت‌هاب به‌صورت خودکار:
  1. وابستگی‌ها را نصب می‌کند
  2. پروژه اندروید Capacitor را می‌سازد
  3. با Gradle فایل APK را تولید می‌کند
  4. APK را در بخش **Actions** به‌صورت Artifact قرار می‌دهد

### مرحله ۳: دانلود و نصب APK
1. در مخزن گیت‌هاب، روی زبانه **Actions** کلیک کنید.
2. آخرین اجرای موفق را باز کنید.
3. در پایین صفحه، بخش **Artifacts** را پیدا و فایل `shadow-operation-debug-apk` را دانلود کنید.
4. فایل ZIP را از حالت فشرده خارج کنید تا `app-debug.apk` به دست آید.
5. فایل APK را به گوشی منتقل و نصب کنید.
   - اگر گوشی اجازه نصب از منابع ناشناخته خواست، آن را فعال کنید (تنظیمات → امنیت → نصب برنامه‌های ناشناخته).

> ✅ نسخه Debug برای نصب و آزمایش اولیه کافی است و نیازی به امضای دیجیتال ندارد.

## 🔄 به‌روزرسانی بازی

1. فایل‌های جدید را در گیت‌هاب آپلود (یا ویرایش) کنید.
2. گیت‌هاب به‌صورت خودکار APK جدید می‌سازد.
3. APK جدید را دانلود و روی گوشی نصب کنید (روی نسخه قبلی نصب می‌شود و پیشرفت بازی حفظ می‌شود).

## 🛠️ ساخت نسخه Release (اختیاری)

برای انتشار در گوگل‌پلی یا نسخه امضاشده:

```bash
npm install
npm run cap:sync      # ساخت www و همگام‌سازی با پروژه اندروید
cd android
./gradlew assembleRelease
```

سپس فایل امضاشده را با Android Studio یا ابزار `jarsigner`/`apksigner` امضا کنید.

## 📁 ساختار پروژه

```
shadow-operation/
├── index.html
├── manifest.json
├── sw.js                      # اجرای آفلاین (PWA)
├── css/
│   ├── style.css              # منو و صفحات
│   ├── game.css               # HUD بازی
│   └── mobile.css             # کنترل لمسی
├── js/
│   ├── lib/three.min.js       # موتور سه‌بعدی (داخلی، آفلاین)
│   ├── main.js                # راه‌اندازی
│   ├── game-engine.js         # موتور بازی و محیط
│   ├── player.js              # بازیکن و سلاح
│   ├── enemies.js             # دشمنان و هوش مصنوعی
│   ├── weapons.js             # سلاح‌ها و ارتقا
│   ├── missions.js            # ۸ مرحله بازی
│   ├── controls.js            # کنترل لمسی و کیبورد
│   ├── audio.js               # صدا و موسیقی
│   ├── ui.js                  # رابط کاربری فارسی
│   └── storage.js             # ذخیره پیشرفت
├── assets/images/icon.svg
├── capacitor.config.json
├── package.json
└── .github/workflows/build-apk.yml
```
> پوشه `www/` هنگام بیلد ساخته می‌شود (فقط فایل‌های لازم بازی وارد APK می‌شوند) و در گیت قرار نمی‌گیرد.
